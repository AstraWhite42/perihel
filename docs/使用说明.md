# 近星点 1.1

macOS 菜单栏 Codex 订阅额度工具。作者：白星澈AstraWhite。

## 系统要求

- Apple Silicon Mac（M 系列芯片），macOS 13 或更高版本。
- 本机安装 Codex CLI，并登录自己的 ChatGPT 订阅账户；不支持 API Key 登录。

## 安装与连接

1. 解压 ZIP，将「近星点.app」拖到「应用程序」目录后打开。
2. 根据首次运行引导检测 Codex CLI。未安装时打开引导中的官方安装说明；已安装 Homebrew 也可运行 `brew install --cask codex`。
3. 点击「打开终端登录」，完成浏览器授权后返回应用，点击「重新检测」和「开始使用」。

应用未进行 Developer ID 签名和 Apple 公证。首次打开如被系统拦截，请确认来源可信，再按「系统设置 → 隐私与安全性」中的提示允许打开。

## 查看额度

点击菜单栏图标打开面板，查看套餐、实际用量、窗口起止、重置倒计时和可用重置次数。点击重置次数可展开到期明细。

进度条表示实际已用，刻度表示匀速预算。点击「领先／落后预算」可展开实际与理论用量表及计算公式；关闭面板后恢复收起。

- **领先预算**：实际已用高于理论已用。
- **落后预算**：实际已用低于理论已用。
- **理论已用**：窗口已过去的时间 ÷ 窗口总时长，限制在 0–100%。窗口开始时间由重置时间减去窗口长度推算。

预算差值按百分点计算，界面以 `%` 显示。所有时间使用系统时区；自然重置与可用的主动重置机会不同。

能量环共有 7 格，左上角三角形占一格。每格余量达到一半时亮，低于一半时熄灭；默认从左上角逆时针熄灭，三角形始终朝顺时针方向。额度未知时百分比显示「—」。

## 设置

右上角齿轮菜单提供：

- **菜单栏显示**：剩余百分比（默认）、领先／落后百分比、不显示百分比。预算正号表示领先，负号表示落后。
- **能量格熄灭方向**：逆时针（默认）或顺时针。顺时针从顶部零点右侧开始熄灭。
- **进度条分段**：按每日零点（默认）、每 24 小时、不分段。
- **主题**：系统原生（默认）或清晰底色。清晰底色在 macOS 14+ 覆盖尖角，macOS 13 尖角保留系统样式。
- 连接引导、选择已有 CLI、退出应用。

设置会自动保存。顶部刷新按钮可手动更新，说明按钮可查看版本及计算口径。默认每两分钟查询一次，打开面板和系统唤醒时补刷。

## 常见问题

- **找不到 CLI**：在引导中点击「选择已有 CLI」，选择实际的 `codex` 可执行文件。
- **无法读取额度**：检查网络、更新 CLI，并确认使用 ChatGPT 账户登录。登录失效时从齿轮菜单重新打开连接引导。
- **开机启动**：在 macOS「登录项」中添加近星点。
- **更新应用**：退出近星点，再用新版替换旧版；目前不支持自动更新。

## 隐私

应用在本机调用 Codex CLI，不包含作者的登录信息，不向作者服务器上传凭据或用量，不发起模型推理，也不消耗重置机会。登录凭据由 CLI 管理。应用仅保存连接引导状态、CLI 路径及界面偏好，不保存额度快照。
