# 近星点使用说明

查看 Codex 额度，比较实际消耗与匀速预算，安排休息或公开重置前的用量。

## 系统要求

- Apple Silicon Mac（M 系列芯片），macOS 13 或更高版本。
- 本机安装 Codex CLI，并登录自己的 ChatGPT 订阅账户；不支持 API Key 登录。

## 安装与首次打开

1. 解压 ZIP，将「近星点.app」拖到「应用程序」目录。
2. 打开应用，在屏幕顶部菜单栏找到近星点图标。
3. 根据首次运行引导连接本机 Codex CLI。

### 提示无法验证或无法打开

应用未进行 Developer ID 签名和 Apple 公证。确认应用来自可信来源后，可在「系统设置 → 隐私与安全性」中按系统提示允许打开。

也可以打开「终端」，执行以下命令，移除近星点的下载隔离标记后启动：

```sh
xattr -dr com.apple.quarantine "/Applications/近星点.app"
open "/Applications/近星点.app"
```

应用不在「应用程序」目录时，将命令中的路径替换为实际位置。命令仅针对该应用，不关闭系统的全局安全检查；移除标记也不能修复真正损坏或不兼容的应用。

- **No such file**：应用路径不正确，先核对位置。
- **Permission denied**：当前用户没有修改权限，可将应用放到自己拥有写入权限的目录，再使用对应路径执行。

### 连接 Codex CLI

1. 按引导检测 CLI。未安装时打开 [官方安装说明](https://learn.chatgpt.com/docs/codex/cli)；已安装 Homebrew 也可运行 `brew install --cask codex`。
2. 点击「打开终端登录」，使用自己的 ChatGPT 账户完成浏览器授权。
3. 返回应用点击「重新检测」，成功后点击「开始使用」。

## 更新与开机启动

- **更新**：从齿轮菜单退出近星点，再用新版替换旧版。新下载的版本如被拦截，可按上面的步骤处理。目前不支持自动更新。
- **开机启动**：在 macOS「登录项」中添加近星点。

## 查看额度

同一额度类别中，周窗口优先展示并用于菜单栏；没有周窗口时使用接口返回的其他窗口。5 小时窗口保留额度卡片和预算差值，不提供展开用量表。接口未提供重置机会时隐藏该区域。

点击菜单栏图标打开面板，查看套餐、实际用量、窗口起止、重置倒计时和可用重置次数。点击重置次数可展开到期明细。

进度条表示实际已用，刻度表示匀速预算。非 5 小时窗口可点击「领先／落后预算」展开实际、当前理论及今晚24时理论用量表，末列显示实际与理论的差值；关闭面板后恢复收起。计算口径可悬停问号查看。

- **领先预算**：实际已用高于理论已用。
- **落后预算**：实际已用低于理论已用。
- **理论已用**：窗口已过去的时间 ÷ 窗口总时长，限制在 0–100%。窗口开始时间由重置时间减去窗口长度推算。

预算差值按百分点计算，界面以 `%` 显示。所有时间使用系统时区；自然重置与可用的主动重置机会不同。

能量环共有 7 格，左上角三角形占一格。每格余量达到一半时亮，低于一半时熄灭；默认从左上角逆时针熄灭，三角形始终朝顺时针方向。额度未知时百分比显示「—」。

## 重置机会

点击「可用重置」展开到期明细。到期时间和距今时长显示在同一行，例如 `10/30 03:00 · 5天5时后`；悬停可看精确到分钟的剩余时长。

进度条上的橙色菱形表示当前窗口内的重置机会到期时间，悬停可看次数和时间。它与公开重置预告的紫色旗标含义不同。接口未提供重置机会时隐藏该区域，明确返回 0 次时仍显示。

## 公开重置消息

周窗口有公开消息时会显示「重置预告」或「重置动向」，可展开原文并打开来源。消息来自独立聚合站 [Codex Resets](https://codex-resets.com)，不是个人账户的重置确认。

有时间的用量重置预告会在当前窗口内显示紫色旗标，用量表中增加预告时点理论量及差值；上限时间会明确标注。时间不明的动向和重置机会发放消息不作为用量目标。消息过期、读取失败或尚未确认执行时会相应提示，不改变原有额度和窗口时间。

应用每 5 分钟独立查询公开消息，不向该信源发送账户、凭据或用量。

## 设置

右上角齿轮菜单提供：

- **菜单栏显示**：剩余百分比（默认）、领先／落后百分比、不显示百分比。预算正号表示领先，负号表示落后。
- **能量格熄灭方向**：逆时针（默认）或顺时针。顺时针从顶部零点右侧开始熄灭。
- **进度条分段**：按自然时点分段（默认）、按等分时长分段、不分段。24 小时及以内的窗口按小时分段，更长窗口按天分段；自然时间对齐整点或零点，固定时长从窗口起点计算。
- **主题**：系统原生（默认）或清晰底色。清晰底色在 macOS 14+ 覆盖尖角，macOS 13 尖角保留系统样式。
- 连接引导、选择已有 CLI、退出应用。

设置会自动保存。顶部刷新按钮可手动更新，说明按钮可查看版本及计算口径。默认每两分钟查询一次，打开面板和系统唤醒时补刷。

## 常见问题

- **找不到 CLI**：在引导中点击「选择已有 CLI」，选择实际的 `codex` 可执行文件。
- **无法读取额度**：检查网络、更新 CLI，并确认使用 ChatGPT 账户登录。登录失效时从齿轮菜单重新打开连接引导。

## 隐私

应用在本机调用 Codex CLI，不包含作者的登录信息，不向作者服务器上传凭据或用量，不发起模型推理，也不消耗重置机会。登录凭据由 CLI 管理。应用仅保存连接引导状态、CLI 路径及界面偏好，不保存额度快照。

公开重置消息会独立连接 Codex Resets，不发送账户、登录凭据或用量。
