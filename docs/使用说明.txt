近星点
作者：白星澈AstraWhite

系统要求
Apple Silicon Mac（M 系列芯片），macOS 13 或更高版本。
需要安装 Codex CLI，并登录自己的 ChatGPT 订阅账户。
无需安装 Xcode、Swift、Node.js 开发环境来运行应用；CLI 的安装要求以官方说明为准。

安装
1. 解压 ZIP，将“近星点.app”拖到“应用程序”目录。
2. 打开应用，在屏幕顶部菜单栏找到星核能量环图标。
3. 首次运行会展开连接引导，检测本机 CLI 和登录状态。
4. 没有 CLI 时按引导打开官方安装说明，或在已安装 Homebrew 的终端中运行：
   brew install --cask codex
5. 点击“打开终端登录”，用自己的 ChatGPT 账户完成浏览器授权。
6. 返回应用点击“重新检测”，检测成功后点击“开始使用”。

本应用未进行 Developer ID 签名和 Apple 公证。首次打开可能需要在“系统设置 → 隐私与安全性”中按系统提示确认来源。只在确认应用来自可信来源后打开，无需关闭系统安全保护。

使用
菜单栏显示剩余百分比。能量环共有 8 格，每 12.5% 一格向上取整；用完后能量格全部变暗。未知额度时显示“—”。点击菜单栏可查看实际与理论用量、窗口时间、重置倒计时和可用重置次数。重置明细可展开查看。设置中的“进度条分段”支持“按每日零点分段”（默认）、“每 24 小时分段”和“不分段”。分段宽度对应实际时长，日期过窄时省略标签。每日零点跟随系统时区，每 24 小时模式从窗口起点计算，短窗口不会强行分成 7 段。

理论用量是按窗口内匀速消耗计算的参考值，窗口开始时间由重置时间减去窗口长度推算。时间使用系统时区。自然重置和可用的主动重置机会是不同概念。

右上角说明按钮可查看版本、作者及计算口径。齿轮菜单可设置“菜单栏显示百分比”；关闭后仅显示动态能量环图标，应用会记住选择。该菜单也可重新打开连接引导、选择 CLI 或退出应用。默认每两分钟查询一次；打开面板和系统唤醒时补刷。

常见问题
找不到 CLI：点击“选择已有 CLI”，选择实际的 codex 可执行文件。应用默认搜索 Homebrew 目录和进程 PATH。
无法读取额度：先确认网络可用、CLI 已更新且登录的是 ChatGPT 订阅账户。API Key 登录不适用于订阅额度监控。
登录失效：从齿轮菜单打开连接引导，重新登录后检测。
自动启动：在 macOS“登录项”中添加近星点。
更新应用：先退出近星点，再用新版替换“应用程序”中的旧版。当前版本不提供自动更新。

隐私
应用在本机调用 Codex CLI 官方接口，不包含作者的登录信息，不向作者服务器上传凭据或用量，不发起模型推理，也不消耗重置机会。登录凭据由 Codex CLI 管理。应用仅保存自定义 CLI 路径、已完成连接引导的状态、百分比显示偏好和进度条分段方式。
