# 近星点（perihel）

原生 macOS 菜单栏 Codex 订阅额度工具，用于比较实际消耗与匀速预算，关注当前、今晚 24 时及公开重置预告时点的用量进度。

支持 Apple Silicon（M 系列芯片），最低目标系统为 macOS 13。需要本机 Codex CLI 和使用者自己的 ChatGPT 订阅登录。不包含 CLI 或登录凭据。

## Windows 预览版

Windows x64 版本使用 WinUI 3，提供动态托盘图标、CLI 连接与登录引导、额度卡片及预算刻度。首次运行点击「开始使用」，之后点击托盘图标查看额度。在托盘溢出区域也能找到「近星点」。

在 Windows 10 2004 或更高版本、安装 .NET 10 SDK 的 x64 开发机上，从仓库根目录执行：

```powershell
dotnet publish Windows/Perihel -c Release -o dist/Windows-x64
.\dist\Windows-x64\Perihel.exe
```

发布目录包含应用和运行时，分发时请保留整个目录。应用自动寻找本机 Codex CLI，支持从引导中选择已有的 EXE 或 npm CMD 入口，也可通过 `--cli-path "完整路径"` 临时指定。设置保存在 `%LOCALAPPDATA%\Perihel\settings.json`，额度快照只保留在内存中。点击卡片右下角的预算差可展开实际、当前理论和今晚 24 时理论；5 小时窗口只显示差值。公开重置消息每 5 分钟独立检查，仅显示在 Codex 周窗口。有效的用量重置预告会同时提供时间轴紫旗和明细中的预告理论行。底部展示可用重置次数和最近到期时间，点击可展开逐次明细。进度条上的橙色菱形标出窗口内的到期时间，悬停可查看同一时刻到期的次数和倒计时。面板按内容调整高度，正文超过 480 DIP 或屏幕可用高度时滚动，工具栏保持可见。

齿轮菜单可切换主题、能量格熄灭方向、托盘显示和进度条分段方式。选择即时生效并自动保存。Windows 通知区域始终只占一个图标位。「剩余百分比」和「领先／落后百分比」直接显示数字，「仅图标」显示能量环。

## macOS 安装与首次运行

1. 解压发布 ZIP，将「近星点.app」拖入「应用程序」目录。
2. 打开应用，根据连接引导安装或选择本机 Codex CLI。
3. 点击「打开终端登录」，使用自己的 ChatGPT 账户授权；返回应用点击「重新检测」和「开始使用」。

已安装 Homebrew 时，可用 `brew install --cask codex` 安装 CLI。API Key 登录不适用于订阅额度监控。

### 被 macOS 拦截时

应用使用临时签名，未进行 Developer ID 签名和 Apple 公证。确认下载来源可信后，可在「系统设置 → 隐私与安全性」中按提示允许打开；也可打开「终端」，只移除本应用的下载隔离标记：

```sh
xattr -dr com.apple.quarantine "/Applications/近星点.app"
open "/Applications/近星点.app"
```

如果应用放在其他位置，请替换为实际路径。该命令递归删除应用内的 `com.apple.quarantine` 属性，不会关闭系统的全局安全检查。它不能修复损坏的文件或不兼容的系统；出现「No such file」应先核对路径，「Permission denied」表示当前用户没有修改权限。

完整安装、使用和更新步骤见 [使用说明](docs/使用说明.md)。

## 功能与设置

### 菜单栏与额度窗口

菜单栏以星核能量环和百分比显示首个额度桶的优先窗口剩余额度，优先选择 `codex` 桶。同一桶内优先展示并使用 7 天窗口；没有周窗口时按主、次窗口顺序回退。5 小时窗口不提供展开用量表。能量环有 7 格，左上角的等边三角形占一格。每格余量达到一半时点亮，低于一半时熄灭；恰好一半时保持点亮。零额度时全部变暗，未知额度时显示暗环及“—”。星核始终点亮，三角形与其他格子一起亮灭。默认从左上角三角形开始逆时针熄灭，可在“能量格熄灭方向”中切换为从顶部零点右侧开始顺时针熄灭；三角形始终顺时针指向。星核与图标布局保持固定，图标自动适配菜单栏深浅色。齿轮菜单的“菜单栏显示”支持“剩余百分比”（默认）、“领先／落后百分比”和“不显示百分比”。预算偏差为实际已用减去理论已用，正号表示领先，负号表示落后；按一位小数显示，持平显示 `0.0%`。不显示百分比时仅保留动态图标。选择会被保存，旧版关闭百分比的偏好会保留为仅图标模式。

内框标题在额度桶名称与窗口时长之间显示套餐，例如“Codex · Pro 100 · 7 天窗口”。优先使用额度桶的 `planType`，缺失时使用账户字段。已确认的套餐映射为正式名称；未知类型及未确认细分名称（如 `edu_plus`、`edu_pro`）保留原始字段，缺失时显示“套餐未知”。

### 进度条与分段

点击菜单栏可查看全部额度窗口、实际与理论用量、窗口时间、重置倒计时和可用重置次数。进度条表示实际已用，刻度表示理论进度。齿轮菜单的“进度条分段”支持“按自然时点分段”（默认）、“按等分时长分段”和“不分段”，选择会被保存。窗口长度不超过 24 小时时按小时分段，更长时按天分段。自然时间按系统时区对齐整点或零点，首末段宽度与实际时长成比例，并遵循夏令时；固定时长从窗口开始时间起按 1 小时或 24 小时划分，不固定段数。日期标签过窄时省略，缺失窗口时间时回退为连续进度条；重置到期明细可展开。时间默认精确到分钟，悬停可查看完整时间。面板随内容自适应高度，超出上限时滚动。顶部 ⓘ 可查看版本、作者和额度说明。

### 刷新与异常状态

默认每两分钟查询，打开面板和系统唤醒时补刷。任一额度桶的任一窗口到期后每 30 秒重试，等待服务端确认新窗口。查询失败保留上次成功快照并显示错误；确认登录失效时清除快照并显示连接引导。百分比模式中的感叹号表示查询失败或窗口已到期。图标模式下可通过悬停和面板查看状态。

### 理论用量与预算差值

非 5 小时窗口的用量表默认收起；点击进度条下方的预算比较可展开实际、当前理论及今晚24时理论用量，并查看实际与理论的差值。差值和午夜理论的计算口径可悬停问号查看。关闭面板后自动恢复收起，数据刷新不改变展开状态。

进度条下方的预算比较中，“领先”表示实际已用高于理论已用，“落后”表示实际已用低于理论已用，差值单位为百分点；按一位小数显示后为零时显示“预算持平”。

理论用量按当前时间在窗口中的进度计算，限制在 0–100%；理论剩余为其补数。开始时间由下次重置时间减去窗口长度推算。理论值仅为消费节奏参考，时间按系统时区显示。

### 主题

齿轮菜单中的“主题”支持“清晰底色”和“系统原生”，默认使用系统原生主题，选择会被保存。清晰底色使用随深浅外观变化的不透明窗口底色；macOS 14+ 通过系统 `NSPopover.hasFullSizeContent` 将背景延伸到尖角，内容仍遵循安全区域。macOS 13 仅应用内容底色，尖角保留系统材质。系统原生主题不铺自定义底色，保留系统弹窗材质。

### 重置机会

可用次数与到期明细来自服务端。到期时间和距今时长合并为一行，悬停可查看精确剩余时间；已到期时明确标注。当前额度窗口内的到期时间以橙色菱形标在进度条上，相同时间合并显示，悬停可查看次数和时间。

## 公开重置消息

周窗口会按需展示 [Codex Resets](https://codex-resets.com) 的公开预告或动向，每 5 分钟独立查询 `/api/v1/status`，支持 ETag 和限流退避。请求不包含 Codex 登录凭据、账户信息或用量。网络失败不影响额度查询，已有消息会标注更新延迟并暂停作为理论目标。

有时间且落在当前周窗口内的用量重置预告显示紫色旗标，展开用量表可查看预告时点理论用量及差值。时间为聚合站提供的参考值；原文含有时间上限表述时显示为上限，不代表个人账户的确定重置时间。时间范围没有结构化字段，不根据原文猜测区间端点。时间已过但未确认执行时显示等待确认。发放重置机会不作为消耗截止目标；动向不显示倒计时或理论目标，失效后隐藏。没有消息时不显示该区域。原文和来源链接保留，具体适用范围以公告为准。

## 数据与隐私

通过官方 `codex app-server` 的 `account/read` 检查登录状态，通过 `account/rateLimits/read` 获取额度。支持多个额度桶和主、次窗口。缺失字段显示“暂无数据”。服务端未提供重置机会时隐藏该区域，明确返回 0 次时仍显示。可用重置次数以 `availableCount` 为准，到期明细可能不完整。额度百分比不能可靠换算为精确的剩余 token 数。

应用不保存凭据和额度快照，不向作者服务器上传数据，不发起模型推理，也不消耗重置机会。登录和凭据更新由本机 CLI 管理。应用保存自定义 CLI 路径、连接引导完成状态、菜单栏显示偏好、进度条分段方式、主题和能量格熄灭方向。点击终端登录时仅生成不含凭据的临时命令文件。

接口文档：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。

## 构建与版本管理

构建需要 Swift 6.0+（Xcode 或 Command Line Tools）。版本信息统一维护在 `version.json`：`version` 为显示版本，`build` 为正整数构建号，`bundleIdentifier` 为应用标识。发布新包时更新版本号，并递增构建号；同一显示版本重新发布也需递增构建号。运行时版本、CLI 客户端标识、Info.plist 和 ZIP 名称均从该文件生成。

```sh
./scripts/build-app.sh
open "dist/近星点.app"
./scripts/package.sh
```

构建固定使用 `arm64-apple-macosx13.0`，不生成 Intel 版本。打包脚本生成 `dist/近星点-版本-build构建号-AppleSilicon.zip` 和 SHA-256 校验文件。ZIP 仅包含应用和使用说明。当前为手动更新：退出应用后替换旧版。

图标由 `scripts/generate-icon.swift` 绘制，构建脚本生成各尺寸 PNG 和 ICNS 并打包。开发预览支持：

```sh
"dist/近星点.app/Contents/MacOS/perihel" --render-preview /tmp/panel.png --dark --expanded
"dist/近星点.app/Contents/MacOS/perihel" --render-preview /tmp/setup.png --setup
"dist/近星点.app/Contents/MacOS/perihel" --render-info /tmp/info.png
"dist/近星点.app/Contents/MacOS/perihel" --render-icon-levels /tmp/icons.png
```

## 诊断

`--probe` 读取本机账户并输出额度摘要，可用 `--cli-path /绝对路径/codex` 指定本次运行使用的 CLI。`--news-probe` 单独检查重置消息接口。渲染预览时可用 `--news-fixture /绝对路径/status.json` 载入本地消息样例。
